# AI and prior work disclosure

ScopePay is original work created during the PayPal AI Hackathon submission period. AI coding assistance helped plan, implement, debug, test, document, edit the demo and prepare submission copy. The participant requested end-to-end execution and personally handled account login/verification and final legal/entry confirmations. No earlier hackathon application source is submitted as this project.

Runtime AI: local Transformers.js / ONNX Runtime, Xenova/all-MiniLM-L6-v2 quantized sentence embeddings. Semantic retrieval suggests catalog services. Review questions are fixed prompts; no generative model infers amounts, quantities or deadlines. Model and dependencies retain original licenses.

PayPal: official existing sandbox REST application, generated business merchant and personal buyer; Orders v2 create/get/capture; no live money, funds, account upgrade or real financial activity. Credentials, local sessions, model cache and account screenshots are excluded.

Media: genuine native local Chrome-window recording, edited with normal-speed excerpts and explicitly labeled application stills. English burned captions and synthetic macOS Daniel narration. Existing standard Node/Python/Pillow/FFmpeg development/media infrastructure reused. An original local Apple ScreenCaptureKit recorder captured only the Chrome content window without microphone audio or background chat. No generated footage substitutes for functionality.

Original source is MIT licensed. Transformers.js/model materials use Apache-2.0; ONNX Runtime MIT; fonts SIL Open Font License. Third-party names are used descriptively.
